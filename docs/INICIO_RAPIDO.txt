OPCIÓN A - Versión Simple (Recomendada para empezar):
────────────────────────────────────────────────────
1. Edita index.html línea 327:
   Cambia: action="send_email.php"
   Por:    action="send_email_simple.php"

2. Edita send_email_simple.php línea 12:
   Cambia: $destinatario = 'angel.pomatay.p@gmail.com';
   Por:    $destinatario = 'TU-EMAIL-REAL@gmail.com';

3. Configura XAMPP para enviar emails:

   En Windows:
   -----------
   a) Edita C:\xampp\php\php.ini:
      Busca [mail function] y configura:

      SMTP = smtp.gmail.com
      smtp_port = 587
      sendmail_from = tu-email@gmail.com

   b) Edita C:\xampp\sendmail\sendmail.ini:

      smtp_server=smtp.gmail.com
      smtp_port=587
      auth_username=tu-email@gmail.com
      auth_password=tu-contraseña-de-app
      force_sender=tu-email@gmail.com

   c) Para Gmail, crea una contraseña de aplicación:
      - Ve a: https://myaccount.google.com/security
      - Activa verificación en 2 pasos
      - Crea contraseña de aplicación
      - Úsala en sendmail.ini

4. Reinicia Apache en XAMPP

El formulario no envía emails:
──────────────────────────────
→ Verifica la configuración de php.ini y sendmail.ini
→ Revisa los logs en: C:\xampp\php\logs\php_error_log
→ Prueba la versión simple: send_email_simple.php
→ Considera usar Formspree como alternativa

Los estilos no se ven:
──────────────────────
→ Limpia la caché del navegador (Ctrl + Shift + R)
→ Verifica que todos los archivos estén en la misma carpeta
→ Revisa la consola del navegador (F12)

El menú móvil no funciona:
──────────────────────────
→ Asegúrate de que script.js esté cargando
→ Revisa la consola del navegador (F12) por errores
→ Verifica la conexión a internet (usa Google Fonts)
